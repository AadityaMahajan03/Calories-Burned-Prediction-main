# 🔥 Calories Burned Prediction

A machine learning web application that predicts estimated calories burned during exercise based on user activity and body metrics.

## 🚀 Features

- Calories burned prediction
- Interactive Streamlit interface
- Random Forest regression model
- Exercise duration analysis
- Heart rate analysis
- Weight and body temperature inputs
- Prediction summary
- Simple and responsive dashboard

## 🧠 Input Features

The model uses:

- Gender
- Age
- Height
- Weight
- Exercise Duration
- Heart Rate
- Body Temperature
